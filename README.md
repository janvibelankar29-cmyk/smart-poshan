# 🌿 SMART POSHAN – Daily Nutrition Distribution Management System

> A complete web application for Anganwadi Centres to simplify daily nutrition distribution record management.

---

## 📋 Project Overview

**Smart Poshan** is a Community Engagement Project (CEP) built to help Anganwadi workers:
- Maintain food stock records
- Track daily nutrition distribution
- Calculate remaining quantities automatically
- Generate monthly reports
- Get low-stock alerts

---

## 🛠️ Technology Stack

| Layer       | Technology          |
|-------------|---------------------|
| Frontend    | React.js + Vite     |
| Styling     | Tailwind CSS        |
| Icons       | Lucide React        |
| Charts      | Recharts            |
| Backend     | Node.js + Express   |
| Database    | SQLite (via better-sqlite3) |

## 🚀 Installation & Setup

### Step 1 – Install Backend
```bash
cd backend
npm install
npm run dev
```
Backend runs at: http://localhost:5000

### Step 2 – Install Frontend
```bash
cd frontend
npm install
npm run dev
```
Frontend runs at: http://localhost:5173
